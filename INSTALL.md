# Install Lantern Hop from the browser

Browsers only allow "Install" on a page served over HTTPS (not from a file on your phone). One-time setup, free:

1. Go to https://app.netlify.com/drop (no account needed to try) and drag this whole folder onto it. Or use GitHub Pages / Cloudflare Pages.
2. Open the link it gives you in Chrome (Android) or Safari (iPhone).
3. Android/Chrome: tap the "Install app" button in the corner (or menu > Install app).
   iPhone/Safari: Share > Add to Home Screen.
4. Open it once while online. After that it works offline.
